# oasa-telematics-desktop
OASA telematics as a desktop app with quality of life improvements.


Its just a wrapper of the OASA Telematics website.
But i added (injected into the HTML) a "Favourites" window that allows you to save your most used stations. 
Made it for personal use because opening the select elements and having to choose the station's info every time i wanted to see arrival times was tedious.

Favourite stations are saved into a `oasa-favorites.json` file in the same directory as the executable, which you can copy and move around into your other devices.
